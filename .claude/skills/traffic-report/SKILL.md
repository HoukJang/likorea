# 트래픽 리포트

## 데이터 소스 (가능한 것부터 시도)

1. **프로덕션 API** (네트워크 허용 시): 관리자 로그인 후 `GET /api/traffic/dashboard?period=7d` 및 `period=30d`.
   - 로그인: `POST /api/users/login` — 자격증명은 사용자에게 요청 (하드코딩 금지)
   - 네트워크 차단(프록시 403) 시 즉시 2번으로 넘어가고, 리포트에 "라이브 조회 불가" 명시
2. **로컬 DB** (MONGO_URI 접근 가능 시): `traffic-analyst` 에이전트에 위임해 TrafficLog/User/BoardPost 컬렉션 집계
3. **둘 다 불가 시**: 사용자에게 관리자 대시보드(`/admin`)와 GA4 확인을 안내하고, 수치 입력을 요청

## 수집 항목

- 기간별(7d/30d) 총 요청 수, 순 사용자 수, 평균 응답시간
- 봇 추정 비율 (userAgent에 bot/crawler/spider 포함 요청 비율)
- 인기 경로 상위 5개
- 등록 사용자 수, 최근 30일 신규 게시글/댓글 수

## 출력

1. 위 항목을 표 하나로 압축한 요약 리포트 (10줄 이내 해설 포함)
2. `.claude/growth/STATE.md`의 "지표 베이스라인" 표 갱신 (값, 확인일, 출처)
3. 직전 베이스라인과 비교해 유의미한 변화가 있으면 한 줄 코멘트

## 토큰 규칙

- 원시 로그를 컨텍스트로 가져오지 말 것 — 집계 쿼리 결과만
- 수집은 `traffic-analyst`(haiku) 에이전트에 위임, 해석·리포트 작성만 메인 모델이 수행
